# Protofio Bootstrap + JavaScript

## Tujuan
Proyek ini dibuat untuk meningkatkan skill coding saya dalam membuat website, khususnya di bidang front-end. Saya ingin terus belajar dan mengasah kemampuan dalam membangun tampilan web yang rapi, fungsional, dan lebih menarik.

## Tools yang Digunakan
- HTML
- CSS
- JavaScript
- Bootstrap

## Cara Menjalankan
1. Download atau clone source code dari repositori ini.
2. Buka folder project.
3. Jalankan file `index.html` di browser.

Anda juga bisa membuka file tersebut menggunakan browser langsung, atau dengan fitur Live Server di VS Code agar lebih nyaman saat pengembangan.

## Fitur
- Layout yang sederhana dan mudah dipahami
- Menggunakan Bootstrap untuk desain yang lebih cepat dan rapi
- Interaksi dasar dengan JavaScript
- Cocok untuk pembelajaran frontend pemula

## Kekurangan
- Desain masih kurang modern
- Tampilan masih terlihat sederhana dan kurang rapi
- Masih perlu banyak pengembangan untuk meningkatkan kualitas UI/UX
